Iker's Tube is a YouTube client for the Nintendo 3DS family, built on top of FourthTube and ThirdTube (GPLv3).

## What's new since 1.0.4

### Player
- **Subtitles.** New "CC" tool turns YouTube subtitles on and cycles their languages. A setting (Subtitles, Open by itself) turns on the language you used last time automatically.
- **Chapters.** New "<< Chap" tool goes to the previous chapter.

## Installing

Install `IkersTube.cia` with FBI, or run `IkersTube.3dsx` from the Homebrew Launcher.
The DSP firmware dump (`sdmc:/3ds/dspfirm.cdc`) is needed for sound.
