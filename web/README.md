# Web

Static site (HTML, CSS, JS, no build step) for Netlify.

- Deploy: connect the repository on Netlify, set **Base directory** to `web` and leave the build command empty
  (`netlify.toml` already publishes the folder), or drag the `web` folder into Netlify Drop.
- Roadmap: edit `js/roadmap.js`.
- Download buttons use `releases/latest/download/...` so they never need updating.
